# 会员订阅教程

> 订阅会员后解锁**无限模拟次数**与全部功能（未订阅用户每日有免费次数上限）。支付方式由后端配置（Stripe ↔ Paddle 一键切换），**支持银行卡 / 微信 / 支付宝**——银行卡流程详见《银行卡订阅教程》。

## 1. 入口

侧边栏 ☰ → **更多** 分组 → **赞助作者**（亦可从个人主页「订阅会员」进入）。

## 2. 订阅流程

### 第一步：查看套餐

1. 进入订阅页（**需先登录**；未登录时显示红色提示"请先登录后再订阅"）。
2. 页面列出 **套餐卡片**（名称、描述、价格与周期），价格示例 `¥X.XX/月、/年、一次性`；
3. 点击套餐卡片选中（默认选中第一个），右上角出现对勾。

### 第二步：去支付

1. 点 **「去支付」** 按钮：
   - 未登录 → 提示"未登录"；
   - 未选套餐 → "请选择套餐"；
   - 成功 → 打开**收银台**（WebView 结算页）。
2. 收银台为 Paddle/Stripe 结算页（外层 WebView），支付完成后服务端将自动激活订阅。

### 第三步：选择支付方式（微信 / 支付宝 / 银行卡）

- 结算页内直接选择银行卡支付 → 流程见《银行卡订阅教程》；
- 若当前会话选择 **微信支付**：WebView 内无法渲染微信二维码，App 会弹出**原生二维码弹窗**：
  - 标题「微信支付」，展示二维码（可用微信扫一扫支付），
  - 按钮 **「微信内打开支付」**（唤起微信）；
- **支付宝支付**：同样弹出二维码弹窗 +「支付宝内打开支付」按提示操作；
- 只有等待后端轮询：支付成功会提示"支付成功"并自动关闭收银台。

### 第四步：确认订阅生效

- 回 App / 切到个人主页查看 **会员状态=已订阅**；
- 未立即更新请等待几秒（后端回调有延迟），或下拉/重进页面。

## 3. 赞助支持（Aptos）

订阅页底部提供捐赠通道（不计入会员）：

- **复制 Aptos 地址**：复制固定 Aptos 钱包地址，用任意 Aptos 钱包转账即可支持开发者（不接受 TRON 等其它链资产）。

## 4. 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 提示未登录 | 先登录再进订阅页 |
| 二维码弹窗或叫不起 | 用浏览器/相机扫二维码；或使用「微信内打开/支付宝内打开」按钮 |
| 支付成功后仍显示未订阅 | 等待回调几秒，重进页面/重启 App 再查看 |
| 选不了套餐 | 网络问题，检查后端可用性 |
