# 设置教程

> 侧边栏 → 设置：App 的全局参数中心（摇杆速度、位置模拟参数、位置偏移、卫星信号、步频模拟、日志、地图 Key、数据备份、个性化等）。全部设置**即时保存**，按分组说明如下。

> 入口：侧边栏 ☰ → **设置** 分组 → 设置。

## 1. 移动

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 摇杆类型 | 圆形 | 圆形 / 按键两种浮窗样式 |
| 步行速度(米/秒) | 1.2 | 摇杆/模拟「步行」档速度 |
| 跑步速度(米/秒) | 3.6 | 摇杆「跑步」档 |
| 驾驶速度(米/秒) | 10.0 | 摇杆「驾驶/开车」档 |

## 2. 位置模拟参数

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 海拔高度(米) | 55~80 | 模拟位置的海拔 |
| 模拟移动速度 (m/s) | 3.05 | 无摇杆时的默认移动速率 |
| 定位精度/定位抖动范围 (米) | 2.5 | 自然抖动关闭=精度；开启后=抖动幅度 |
| 最少模拟卫星数量 | 12 | 仅支持北斗卫星；配 卫星信号模拟 |
| 上报位置频率 (ms) | 200 | 越低越频繁；耗电越高 |

## 3. 位置偏移

- **随机偏移**（关）：仅在使用**历史位置**时生效——每次使用历史坐标在其中加随机小偏移，避免应用点名认出固定坐标；
- **经度 / 纬度最大偏移距离(米)**（各 10.0）：随机偏移的范围上限。

## 4. 卫星与信号模拟

- **模拟 GPS 卫星信号**（开）：伪造北斗卫星数量与信号强度（给测绘/卫星类应用看）。

## 5. 步频模拟

- **启用步频模拟**（开）：为计步类应用模拟步频数据；
- **步频数据类型**：傅里叶级数 (Fourier) / 正弦+随机扰动 (Sine+Noise) 两种模拟方案；
- **自然 GPS 抖动**（关）：在注入位置上叠加漂移，让轨迹像真实 GPS 一样晃动（要求"真实感"时开，要求稳定时关）。

## 6. 记录（日志）

- **启用日志 / 启用详细调试日志**（关）：写入本地日志文件；详细日志**增加耗电**，排查故障时开；
- **导出日志**：系统保存对话框导出 `kail_location_logs.txt`；
- **清除日志缓存**：显示当前缓存大小，确认后清除。

## 7. 其他

| 设置项 | 说明 |
| --- | --- |
| 模拟时临时关闭 SELinux | 开：从开始模拟到停止切换为宽容模式（注入/服务全部放行），停止后自动恢复强制；**Android 14/15 绑定服务被拦截时打开** |
| 百度地图 Key (需重启生效) | 高级用户可填写自己的百度 AK |
| OpenCellID API Key | 供基站模拟从网络查基站；在 opencellid.org 注册获取 |
| 历史记录有效期(天) | 7 天：超过期自动清理历史 |

## 8. Xposed 模块

- **隐藏 Xposed 模块**（需 Root）：`pm hide` 把模块从桌面与 LSPosed 列表藏掉，降低被发现概率；再关一次恢复显示。副标题显示当前状态（检测中…/已隐藏/显示中）。

## 9. 数据备份

- **导出数据**：选择要备份的类别（按运行模式分组，逐项列出"（N 项）/（无数据）"，无数据的置灰）→ 生成 `.bak` 备份文件（系统保存对话框，默认 `kail_location_backup.bak`）；
- **导入数据**：选 `.bak` 文件 → 选择要恢复的类别 → 导入，提示"已导入 N 项菜单数据，**重启应用后生效**"。

## 10. 个性化

- **浮窗大小**：摇杆/悬浮窗面板的 宽 x 高（默认 300 x 500）；
- **悬浮窗地图缩放比例**：10~21（越大越详细，默认 17）；
- **当前版本**：只读，查看 App 版本号。

## 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 改了什么没生效 | 大多数即时生效；百度 Key 需重启应用；备份导入需重启应用 |
| 打开某应用被拉回真位置 | 检查「自然 GPS 抖动」、是否需要「反定位拉回」（Xposed 设置）、临时关闭 SELinux |
| 日志很大 | 关闭详细调试日志，并定期「清除日志缓存」 |
