# 基站模拟教程

> Kail Location 的「基站模拟」：伪造手机所处的基站（蜂窝小区）信息——网络制式、MCC/MNC、LAC/TAC、CID、PSC/PCI、基站经纬度与覆盖半径，让目标 App 的 `TelephonyManager.getAllCellInfo / getCellLocation` 等读到假的基站列表。常用于 WiFi/基站定位类应用的测试。

> **需要 Root 模式**，入口仅在 Root 模式侧边栏显示。

## 1. 开始之前

- 侧边栏「运行模式」= **Root 模式**，root 已授权。
- 已 **登录**，订阅或免费次数充足（开始模拟时扣一次）。
- 本机扫描基站需要 **电话状态权限 + 定位权限**；「从网络获取」还需在设置里配置 **OpenCellID API Key**。

## 2. 操作步骤

### 添加基站（三种方式）

**方式一：手动添加**

1. 点右上角 **+（添加基站）**，弹出「添加基站」窗口：
   - **网络类型**：GSM / CDMA / LTE / WCDMA（默认 LTE）；
   - **MCC**（默认 460）、**MNC**（默认 0）、**LAC/TAC**（默认 0）、**CID/CellId**（默认 0）、**PSC/PCI**（默认 0）；
   - **纬度 / 经度 / 覆盖半径(米)**（默认 0 / 0 / 1000）；
   - 点确定保存（非法值自动回退默认），保存后自动勾选该基站。

**方式二：扫描当前位置基站**

1. 点 **「获取当前位置基站」**（搜索图标按钮）。
2. 弹出「扫描到的基站」列表：每个小区显示 `制式-CID`、MCC/MNC/LAC/PSC、位置（经纬度）；
3. 点 **「全部添加」** 一键加入清单（或点「取消」）。扫描中显示"正在扫描基站..."。

**方式三：从网络获取**

1. 点 **「从网络获取」**（转圈图标按钮），用当前定位坐标（WGS84）查 OpenCellID（半径 0.5km）。
2. 成功同样进入「扫描到的基站」弹窗；失败会提示（未定位 / 未配置 Key / 无数据 / 网络失败）。

### 管理清单与选择

- 每行：勾选框 + `制式 - CID` 等信息 + **铅笔（编辑）** + **垃圾桶（删除）**（删除会同步取消勾选）；
- 顶部右侧 **「全选 / 取消全选」**；显示「已添加的基站（N）」；
- 空态提示："暂无模拟基站，点击下方按钮扫描或添加基站"。

### 开始 / 停止模拟

1. 至少勾选 1 个基站后，顶部卡片出现 **「开始模拟」**；
2. 开始后卡片显示 **「基站模拟运行中」+「运行中」** 徽章，按钮变红色 **「停止模拟」**；列表预览最多 3 个，多的显示 "+ N 更多..."；
3. 模拟期间扫描/添加/编辑全部禁用，仅 **停止模拟** 可用；
4. 停止模拟后恢复编辑。状态已持久化，杀掉 App 重进仍是模拟中/停止状态（以"停止模拟"为准）。

## 3. 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 侧边栏没有「基站模拟」 | 先切换为 Root 模式 |
| 扫描基站为空 | 确认定位权限 + 电话权限，站在信号好的室外再试 |
| 从网络获取失败 | 先在「设置」中配置 OpenCellID API Key（opencellid.org 注册），并确保已定位 |
| 开始模拟提示未登录/次数用完 | 先登录；检查订阅/次数 |
| 模拟后 App 仍显示真实基站 | 目标应用可能缓存了数据，重启该应用再试；仍不行导出日志反馈 |
