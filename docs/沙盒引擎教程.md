# 沙盒引擎教程

> Kail Location 的「沙盒引擎」：基于 **BlackBox 虚拟化**，把已安装的第三方应用**克隆进沙盒**独立运行，并在沙盒进程内注入模拟位置/步频——**不需要 Root，也不需要开发者选项**。适合"只想让某些应用假定位"的场景（克隆的应用读到假的 GPS，本体应用不受影响）。

> 仅当运行模式为 **沙盒模式** 时，侧边栏「设置 → 运行模式 → 沙盒模式」之下会出现「沙盒引擎」入口。

## 1. 开始之前

- 在侧边栏「运行模式」对话框中选择 **沙盒模式**，确认入口「沙盒引擎」出现。
- 克隆哪些操作：
  - 克隆应用需是**非系统应用**、未在沙盒内、ABI 兼容；
  - 克隆应用启动、接收假定位都在沙盒环境内进行。

## 2. 操作步骤

### 克隆应用（安装进沙盒）

1. 进入「沙盒引擎」，点右上角 **+**（或右下角 FAB **+**）；
2. 弹出「克隆应用」窗口：3 列网格列出可克隆的应用，顶部搜索框过滤；
3. 点击任意应用即克隆，成功后提示「安装成功」，列表刷新；
4. 列表为空时可点 **「加载系统应用列表」** 重新加载。

### 启动与操作沙盒应用

- 主界面网格：图标 + 名称 + 三按钮 **「创建快捷方式」/「清除数据」/「卸载」**；
- **点击卡片 = 启动应用**（启动后进入沙盒内运行，定位 API 被沙盒注入层接管）；
- **长按卡片 = 弹出菜单**：启动应用 / 清除数据 / 停止运行 / 卸载应用（红）。
- 空态提示："沙盒中暂无应用，点击右下角 + 按钮克隆应用"。

### 创建桌面快捷方式

- 点卡片「创建快捷方式」→ 系统弹"固定到桌面"确认 → 快捷方式图标点击即快速启动该沙盒应用（指向沙盒）。

### 沙盒设置（右上角齿轮）

点顶栏 ⚙ 弹出「沙盒设置」：

| 项目 | 说明 |
| --- | --- |
| 隐藏 Root | 对沙盒应用隐藏 Root 权限（切换后提示"重启应用生效"） |
| 守护进程 | 保持沙盒服务后台运行 |
| 使用 VPN 网络 | 通过 VPN 路由流量，可能改善网络 |
| 禁用 FLAG_SECURE | 允许在沙盒应用内截屏/录屏 |
| 步频模拟 | 为沙盒应用模拟步频传感器；下方可调 **步频（30~240 步/分）** 滑块，即时生效 |
| GMS 管理 | 管理 Google 服务框架（当前为"功能开发中"/设备不支持则置灰） |
| 发送日志 | 上传调试日志到开发者（"正在发送日志..."→"日志发送成功/失败"） |

### 卸载 / 清除数据 / 停止运行

- 长按菜单或卡片按钮操作；成功提示「卸载成功」「清除成功」「已停止运行」等。

## 3. 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 没有「沙盒引擎」入口 | 先在运行模式中选择「沙盒模式」 |
| 克隆应用列表为空 | 点「加载系统应用列表」重载；确认应用为非系统应用 |
| 克隆/安装失败 | 该应用 ABI 不兼容或已在沙盒内；用别的应用试试 |
| 沙盒应用定位没生效 | 确认在位置模拟页启动的是沙盒模式（运行模式=沙盒），克隆的应用要从沙盒内启动 |
| 快捷方式创建失败 | 系统限制时改用应用内点击启动 |
