# 摄像头模拟教程

> Kail Location 的「模拟摄像头」：把目标应用的**相机取景画⾯替换为指定视频 / 图片 / 网络串流**，也可替换拍照结果、模拟麦克风输入——可用于监控类、识货类应用的替换与测试。

> **支持 Root / Xposed 两种模式**（root 直接注入，xposed 由模块处理）；侧边栏在 Root 或 Xposed 模式下显示。

## 1. 开始之前

- Root 模式：root 授权已就绪，且**开机满 100 秒**（不足会提示"系统未就绪，请开机 100 秒后再试"）。
- Xposed 模式：已安装 KailLocation Xposed 模块且版本一致，**在 LSPosed 中勾选要模拟的应用作用域**。
- 已 **登录**，订阅或免费次数充足（开始模拟时扣一次）。
- 悬浮窗控制（可选）：需要「悬浮窗」权限；通知栏控制：允许通知。

## 2. 操作步骤

### 第一步：导入媒体素材

1. 主页面：点右上角 **+** 按钮，从系统选择器选一个**视频**，自动复制到媒体库并设为当前视频（提示"已导入视频: xxx"）；再次点 + 可继续导入多个。
2. 主页列表：**点击任意视频**切换为当前（标记"当前使用"）；**X 删除**（如删除当前视频会清空当前选择）。

### 第二步：设置模拟参数（右上角齿轮）

点击顶栏 **齿轮** 进入设置页，按需配置：

| 分组 | 项目 | 说明 |
| --- | --- | --- |
| 媒体来源 | 本地视频 / 网络流 | 网络流需要填 **RTSP/HLS/HTTP 地址** |
| 替换模式 | 视频 / 图片 | 仅本地来源可选；选图片后导入图片 |
| 旋转偏移 | 0° / 90° / 180° / 270° | 把画面旋转成目标应用期望的横竖方向 |
| 开关 | 拍照替换 | 拍照结果用视频帧/图片顶替 |
| 开关 | 播放视频声音 | |
| 开关 | 随机播放 | 每次相机启动从视频库随机选 |
| 麦克风 | 关闭 / 静音 / 替换 / 视频同步 | 替换时导入音频文件 |
| 控制面 | 通知栏控制 / 悬浮窗控制 | 立即生效，开启后出现后台控制按钮 |
| 目标应用 | 目标应用（已选 N）+ 搜索 + 勾选 | **至少勾选 1 个应用**，改动即时生效 |

### 第三步：开始模拟

1. 回到主页，确认顶部状态卡显示"当前视频 / 已选 N 个目标应用"。
2. 点 **「开始模拟」**，状态行显示"正在下发配置并注入…（后台继续，可离开页面）"；完成后即为「模拟摄像头运行中」。
3. 打开目标应用相机，预览画面即替换。

### 第四步：模拟中的控制

- **通知栏控制**：常驻通知「模拟摄像头运行中」+ 四个按钮：**上一个 / 下一个 / 旋转+90° / 关闭**；点通知体回到本页。
- **悬浮窗控制**：右下角悬浮面板，按钮 **◀ 上一个 / ▶ 下一个 / ⟳ 旋转+90° / ✕ 关闭**（无悬浮窗权限时自动不显示）。
- 模拟中随时改设置/换视频，都会**立即重新下发并生效**。

### 第五步：停止模拟

点红色 **「停止模拟」** 即恢复目标应用原始相机画面。

## 3. 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 侧边栏没有该入口 | 需要 Root 或 Xposed 模式；未安装模块时抽屉会提示下载 |
| 开始模拟提示开机不满 100 秒 | 等待提示时间后再试 |
| 状态行提示"请先选择目标应用" | 到设置页勾选至少 1 个目标应用 |
| 目标应用仍是真相机 | Xposed 模式务必在 LSPosed 勾选该应用作用域；Root 模式重启目标应用 |
| 悬浮窗控制不显示 | 授予「悬浮窗」权限；或改用通知栏控制 |
| 视频方向不对 | 用旋转偏移（90°/180°/270°）调整 |

## 4. 帮助按钮（?）

主页 6 项、设置页 23 项数字角标引导，点任意处关闭。
