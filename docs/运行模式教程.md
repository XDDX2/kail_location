# 运行模式教程

> Kail Location 支持四种「运行模式」，决定模拟数据以何种方式注入系统。位置模拟/路线模拟/导航模拟在四种模式下都可用；部分高级模拟（WiFi/基站/摄像头/独立模拟/Root隐藏/沙盒/Xposed设置）只在特定模式下显示。

## 1. 切换方法

1. 打开侧边栏（☰）→ **「设置」分组 → 运行模式**；
2. 弹窗「选择运行模式」，四选一（点选即切换，提示"运行模式已切换为 %s"）；
3. 切换会立即持久化——底层各页面按模式启动对应服务。

## 2. 如果切换条件不满足：


- **开发者模式**：探测未授权 → 自动打开系统「开发者选项 → 选择模拟位置信息应用」并提示在那边设置；设置好后回 App 自动切回开发者模式。
- **Xposed 模式**：无模块/版本不匹配 → 弹下载框（见《Xposed 模式教程》）。
- **Root 模式**：直接切换即可（无 root 时后续模拟不可用，模拟页会提示）。

## 3. 不同模式下的可用功能


见菜单显示为准

## 4. 选择建议

- 只想快速开始（有开发者选项）：用 **开发者模式**；
- 需要最大化注入与防检测（各种高级模拟）：用 **Root 模式**；
- 有 LSPosed 且需要高度定制（隐藏 mock 标记等）：**Xposed 模式**；
- 没有 root、也不想动开发者选项：**沙盒模式**（克隆应用到沙盒）。

## 5. 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 选了开发者模式却提示去设置 | 按提示在系统开发者选项里选中本应用 |
| 换模式后模拟还在跑 | 强烈建议先停止当前模拟再切换；切换后各页面按新模式重新启动 |
| 找不到某个高级模拟入口 | 该功能只在对应模式显示（见上表） |
