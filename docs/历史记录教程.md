# 历史记录教程

> Kail Location 保存两种历史：**位置历史**（选过的模拟点）与**路线历史**（导航/路线模拟的记录）。这里重点介绍位置历史的管理（在"历史记录"页与主界面 Tab 都能操作）。

## 1. 哪里能看到

| 位置 | 入口 | 内容 |
| --- | --- | --- |
| 主界面下方 Tab | 「常用 / 历史」两个页签 | 收藏（常用）与全部位置历史；可直接点击设为目标 |
| 历史记录页 | 侧边栏进入选点页 → 侧边栏菜单 → 历史记录 | 大列表 + 搜索 + 批量清空，点选返回坐标 |

## 2. 历史记录页操作

1. **搜索**：顶部搜索框，按名称/时间过滤（即时），右侧叉号清除；
2. **点击一条记录**：选中该位置返回上级（条目显示 WGS84 与 BD09 两组坐标）；
3. **长按一条记录**：弹出菜单 →
   - **编辑**：改名称；
   - **删除**：确认后删除；
4. **右上垃圾桶（删除全部）**：确认「确定要删除全部历史记录吗?」后全部清空；
5. 空列表显示「暂无历史记录」。

## 3. 主界面（位置模拟）Tab 操作

- **收藏 Tab（常用）**：只显示收藏的位置；可**长按拖动排序**（靠前的优先展示）；每行有 星标/铅笔/垃圾桶；
- **历史 Tab**：全部历史，按时间倒序；
- 两 Tab 都有搜索按钮（按名称/时间过滤）；
- 单击任意记录 → 设为当前模拟位置。

## 4. 自动保存与清理

- 每次选点（地图选点/搜索/输入坐标/点历史）都会自动存入历史（同坐标去重，保留收藏状态；重名会带时间戳）；
- **历史记录有效期(天)**（默认 7 天）：「设置 → 其他」可改；过期记录自动删除；
- **随机偏移**（设置 → 位置偏移，默认关）：开启后点历史记录时对坐标加随机偏移（提示"经度偏移/纬度偏移"），避免固定坐标特征。

## 5. 路线历史（导航模拟）

- 导航模拟底部 Tab「收藏 / 历史位置」：`起点 → 终点` 记录，最多保留最近 10 条；星标/重命名/删除/收藏拖动排序同位置历史。

## 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 历史数据突然变少 | 超过了有效期自动清理（默认 7 天）；可在设置里改大 |
| 点了历史位置没生效 | 历史页是"返回选中坐标"；在主界面 Tab 点才是设为目标 |
| 收藏顺序不对 | 在「常用」Tab 长按拖动排序 |
