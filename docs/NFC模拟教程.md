# NFC 模拟教程

> Kail Location 的「NFC 模拟」：真机读取 NFC 标签得到内容（URL/文本），然后**用软件方式模拟发送**：构造一条 NDEF 发现 Intent 投递给目标应用，让目标应用以为收到一个 NFC 标签。**不要求 root，也不需要位置模拟**。

## 1. 开始之前

- 手机需有 **NFC 硬件** 且 **NFC 开关已打开**（打开后 App 会提示"NFC状态：正常"；未开启提示"请先开启NFC"）。
- 点击 **「发送」** 需要 **已登录** 且订阅或免费次数充足。

## 2. 操作步骤

### 读取一个 NFC 标签

1. 保持 NFC 模拟页面在前台。
2. 拿任意 NFC 标签（卡片、贴纸、工牌等）**靠近手机 NFC 区域**。
3. 页面出现绿色「读取成功」卡片：
   - **标签 ID**（如 `04:23:45:AB:...`）；
   - **标签类型**（如 `android.nfc.tech.Ndef,...`）；
   - **内容**（NDEF 文本/URL，最多 2 行）。
4. 读取成功后，自动把解析出的 **URL** 和 **应用包名** 填入下方发送表单，并自动加入历史记录。

### 模拟发送

1. 确认输入框：
   - **URL地址**：自动填充（没有 http 前缀会自动补 `https://`）；
   - **应用包名**：自动填充（从内容中解析，如 `com.autonavi.minimap`）。
2. 也可以手动改成目标应用名和包名。
3. 点 **「发送」**：
   - 成功提示 **"已发送: <URL或包名>"**；若目标应用无法处理 NDEF 还会兜底打开 URL（提示"已打开"）；
   - 失败提示"发送失败: ..."。
4. 手动发送成功的数据也会存入历史（类型 `manual`）。

### 历史记录

- 标题「历史记录」，右上 **清空**（红色）一键清空全部；
- 每条：名称（可空）、内容、`类型 • MM-dd HH:mm`；
- **点击某条记录**：自动填入 URL / 包名再次发送；
- 右侧三个按钮：**星标（收藏，置顶）**、**铅笔（重命名）**、**垃圾桶（删除）**；
- 历史最多保留 50 条。

## 3. 常见问题

| 问题 | 解决办法 |
| --- | --- |
| NFC 读不到标签 | 确认 NFC 已开启、卡片有 NCF 芯片（可换一张试试） |
| 发送提示"请先登录" | 先到侧边栏头部登录 |
| 发送提示次数用完 | 订阅会员或等待次日免费次数重置 |
| 目标应用无反应 | 该应用可能不处理 NDEF 协议，试试用包名的应用（如地图/微信扫码） |

## 4. 说明

- NFC 模拟发送是**纯软件行为**（Intent 广播），不会真的发射射频信号。
- 每个页面右上角 **?** 可查看该页按钮说明。
