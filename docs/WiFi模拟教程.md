# WiFi 模拟教程

> Kail Location 的「WiFi 模拟」：伪造 WiFi 扫描结果——让目标 App 的 `WifiManager.getScanResults()` 返回你指定的 SSID / 信号强度列表，用于测试依赖 WiFi 周围信息的应用（如 WiFi 定位、室内地图、逆向开发）。

> **需要 Root 模式**（依托 FakeLocation 注入层），入口仅在 Root 模式侧边栏显示。

## 1. 开始之前

- 侧边栏「运行模式」已切换为 **Root 模式**，且已授权 root（Magisk/KernelSU）。
- WiFi 开关已开启（扫描用）；定位权限已授予。
- 已 **登录**，订阅或免费次数充足（开始模拟时扣一次）。

## 2. 操作步骤

### 添加要模拟的 WiFi（两种方式）

**方式一：扫描附近 WiFi（自动）**

1. 点页面顶部按钮 **「扫描附近WiFi」**（有列表时在左上角）。
2. 弹窗「扫描到的WiFi」显示附近热点列表（SSID + BSSID · 信号 · 频率），点 **「添加」** 逐个加入（自动勾选）。
3. 没扫到？弹窗提示"未扫描到WiFi，请确保WiFi已开启并处于信号覆盖区域"。

**方式二：手动录入**

1. 点右上角 **+（添加 WiFi）** 进入 WiFi 选择页，再点 **+** 打开「手动添加WiFi」：
   - **名称**（可选，列表显示名）、**SSID**、**BSSID (MAC)**、**信号强度 (dBm)**、**频率 (MHz)**、**加密方式**（如 `[WPA-PSK-CCMP]`）；
   - SSID 与 BSSID 都填了才能点确定；保存后自动选中并返回。
2. 也可在此页点「扫描附近WiFi」扫现实附近热点添加到列表。

### 管理清单

- 每行：勾选框 + 名称 + `ssid · bssid` + **铅笔（重命名）** + **垃圾桶（删除）**；
- 顶部 **「全选 / 取消全选」** 一键勾选全部；
- 显示「已添加的 Wi-Fi（N）」计数。

### 开始 / 停止模拟

1. 勾选至少一个 WiFi 后，顶部卡片出现 **「开始模拟」** 按钮，点击即开始。
2. 开始后卡片显示 **「WiFi模拟运行中」+「运行中」** 徽章，按钮变红色 **「停止模拟」**；列表预览最多显示 3 条，更多显示 "+ N 更多..."。
3. 模拟期间页面编辑/勾选/扫描全部禁用，只有 **停止模拟** 和右上角 ? 可点；停止后恢复正常编辑。

## 3. 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 侧边栏没有「WiFi模拟」 | 当前不是 Root 模式，先切换运行模式 |
| 开始模拟提示未登录/次数用完 | 先登录；检查订阅状态 |
| 扫描结果为空 | 打开 WiFi 开关、靠近路由器；检查定位权限 |
| 模拟后 App 仍读到真实 WiFi | 确认注入链生效（重启目标 App）；查看日志反馈给开发者 |

## 4. 说明

- WiFi 模拟**独立于位置模拟**：只改 WiFi 数据，不会顺带改定位（也可能清理残留的 GPS mock）。
- 每个页面右上角 ? 可查看该页按钮说明。
