# Xposed 模式教程

> Xposed 模式：通过官方 **KailLocation Xposed 模块**（`com.kail.locationxposed`）在 LSPosed/Xposed 框架层 hook 系统定位，实现更彻底的模拟（卫星信号伪造、隐藏模拟标记、反拉回等）。需要 **LSPosed 环境**，无需 Root 命令行部署（模块自身负责 hook）。

## 1. 前置条件

- 手机已安装并启用 **LSPosed（或 Xposed 框架）**。
- 已安装 **KailLocation Xposed 模块**，且模块版本号与 App 当前版本号**完全一致**。

## 2. 安装 / 更新 Xposed 模块

1. 打开侧边栏 → **「运行模式」**，选择 **「Xposed 模式」**：
   - 未检测到模块 → 弹窗「未检测到 Xposed 模块」→ 点 **「前往下载」**；
   - 版本不一致 → 弹窗「Xposed 模块版本不匹配」→ 同上；
   - 下载显示进度条（`KailLocationXposed.apk`，来自 GitHub Releases），完成后自动调起系统安装器。
2. 安装完成后：在 **LSPosed 模块列表**中启用本 App 的 Xposed 模块，并勾选**要模拟的目标应用作用域**（这是关键一步）。
3. 再回 App 运行模式选「Xposed 模式」，切换成功提示"运行模式已切换为 Xposed 模式"。

## 3. Xposed 设置（常用开关）

Xposed 模式下侧边栏出现 **「Xposed 设置」**，点击进入，全部**即改即生效**（后续模拟持续生效）：

| 分组 | 项目 | 默认 | 说明 |
| --- | --- | --- | --- |
| 卫星与信号模拟 | 模拟 GPS 卫星信号 | 开 | 伪造北斗卫星数量与信号强度 |
| | 禁用融合定位 | 关 | 阻止应用用 fused provider |
| | 隐藏模拟位置 | 关 | 移除 `isFromMockProvider` 标记（App 不易发现你是模拟） |
| | 禁用扫描 WiFi 列表 | 关 | 阻止应用拿到真实 WiFi 扫描结果 |
| | 网络定位降级为 CDMA | 关 | 把网络定位结果伪装成基站定位 |
| 反检测与防拉回 | 反定位拉回 | 关 | 持续广播位置，缓解被系统拉回 |
| 拦截与降级控制 | 最少模拟卫星数量 | 12 | 仅支持北斗口径 |
| | 上报位置频率 (ms) | 200 | 越低越频繁，耗电越高 |

- 开关项点击即切换；输入项（卫星/频率）点击弹输入框，填数字确定（留空不保存，显示"未设置"）。

## 4. 开始模拟并选择运行模式

1. 该设置就绪后，回到位置模拟/路线判断等页面正常使用模拟功能即可（模拟由模块按上述设置 hook）。
2. 常用提醒：
   - 目标应用若未在 LSPosed 作用域勾选，模块不会对它生效；
   - 修改模块设置后建议重启对应目标应用。

## 5. 隐藏 / 恢复 Xposed 模块（可选，需 Root）

在 **「设置 → Xposed 模块」** 分组：

- 开关 **「隐藏 Xposed 模块」**：把模块从桌面与 LSPosed 模块列表「打开」按钮中藏掉（`pm hide`，需要 Root shell），降低被目标应用发现的风险；
- 再次关闭开关可恢复显示；
- 开关状态显示：检测中… / 已隐藏 / 显示中（无 Root 或模块不存在时禁用）。

## 6. 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 选择 Xposed 模式提示未找到/版本不匹配 | 按弹窗「前往下载」安装/更新一致版本模块 |
| 模块装了但模拟不生效 | 确认已在 LSPosed 启用模块并勾选目标应用作用域；重启目标应用 |
| 设置里隐藏了模块找不到了 | 通过本 App 设置页「隐藏 Xposed 模块」开关恢复 |
| 需要更强的防检测 | 结合「反定位拉回」「隐藏模拟位置」「最少卫星数」等设置 |
