# 银行卡订阅教程

> 本教程说明如何通过 **银行卡（信用卡/借记卡）** 完成会员订阅。整个流程包含 5 个环节：填写邮箱 → 选择银行卡支付 → 填写地址 → 提交卡片信息（卡号/有效期/安全码）→ 收取银行验证码并完成付款。

---

## 1. 流程总览

```
开始
 │
 ├─ 第一步：填写联系邮箱
 ├─ 第二步：选择「银行卡支付」
 ├─ 第三步：填写收货地址
 ├─ 第四步：填写银行卡信息（卡号 / 有效期 / 安全码）
 ├─ 第五步：接收银行验证码并确认支付
 └─ 完成：会员订阅生效
```

> 全程由 **Stripe（国际支付平台）** 处理银行卡交易，本应用只负责打开结算页面，不会接触或保存你的银行卡信息。

---

## 2. 第一步：填写联系邮箱

1. 打开 Kail Location，进入 **赞助 / 购买（会员订阅）页面**。
2. 在出现的结算页中，首先填写 **邮箱（Email）**。
3. 输入你常用的真实邮箱（建议使用邮箱客户端可正常收发邮件的地址），点 **Continue（继续）**。
4. 留意邮箱，部分情况下会向你发送确认邮件或收据。

> 提示：邮箱用于接收订单收据与后续会员相关通知，请填写能正常收取邮件的地址。

---

## 3. 第二步：选择银行卡支付

1. 在付款方式区域，选择 **卡片 / Card（银行卡支付）**。
2. 页面上会出现卡片图标栏目，用于输入银行卡信息（见第四步）。
3. 如页面提供其他支付方式（如支付宝、微信、Link 等），**不要**选择，只需确认选中「Card / 银行卡」即可。

---

## 4. 第三步：填写收货地址

> 原因说明：按国际卡组织的合规要求（如欧洲 SCA 法规），银行需要在支付时校验卡片账单地址，因此需要先填写地址。

1. 在账单 / 收货地址区域（Billing Address / Delivery Address）开始填写。
2. 依次填写：
   - **姓名（Name）**：与银行卡持卡人一致；
   - **国家或地区（Country）**：选择你所在国家；
   - **地址 1（Address / 街道）**：可先填写城市名，街道名称非必填；
   - **城市（City）**；
   - **邮编（Postal Code / ZIP）**：必填；
   - **省份 / 州（State / Province）**：如手机号填不了，可只填城市和邮编。
3. 填写完成后点 **Continue（继续）**。

> 提示：
> - 地址不要求精确到门牌号，但 **国家、城市、邮编** 必须填写，且需与发卡行预留信息基本一致。
> - 如果不确定，可以先只填城市（City）和邮编（Postal Code），一般也能通过。

---

## 5. 第四步：填写银行卡信息

### 5.1 找到银行卡卡号（Card Number）

1. 翻看你的实体银行卡 **正面**：
   - 现代卡片（如银联金卡/白金卡、Visa、Mastercard）卡号通常印在正面中部，是一串 **16 位数字**。
   - 老式卡片或背面翻看时，卡号可能印在反面签名条上方。
2. 在支付页的「卡号」输入框中，**连续输入这串数字，不要加空格**；输入过程中卡片品牌图标（Visa / Mastercard / UnionPay）会自动识别。

> 常见卡号开头：
> - **4** 开头 → Visa
> - **5** 开头 → Mastercard
> - **62 / 621** 开头 → 银联

### 5.2 找到卡片有效期（Expiry Date / "MM/YY"）

1. 在卡片正面上查找形如 **MM/YY**、**MM/YYYY** 的小字，例如 `09/28` 表示 2028 年 9 月过期。
2. 在输入框中按「月 / 年」顺序输入，如 `09/28`。

> 注意：填写的是 **过期时间**，起点是卡片失效当月，不要填到手当天日期。

### 5.3 找到安全码（CVV / CVC）

1. **Visa / Mastercard / 银联卡**：翻到卡片 **背面**，签名条右侧的 **最后 3 位数字** 即安全码（也称 CVV / CVC / 信用卡背面校验码）。
2. 在支付页的「CVV / CVC」输入框中输入这 3 位数字，点击 **Continue（继续）**。

> 安全码只用于本次支付验证，**不要**将卡号、有效期、安全码发给任何人（包括所谓的"客服"）。

---

## 6. 第五步：接收银行验证码并完成支付

### 6.1 触发银行验证

- 提交卡片信息后，你的发卡银行（如招商银行 / 建设银行 / 工商银行等）会根据风控要求，向你的 **预留手机号** 发送一条 **6 位验证码** 短信（内容类似「您正在进行网上支付，验证码为 XXXXXX，请勿泄露」）。
- 部分银行不带短信发送验证码时，也可能要求你在 **银行 App** 内确认（例如弹出"允许本次交易"提示，点击确认即可）。

### 6.2 输入验证码

1. 回到支付页面，输入银行短信中的 6 位验证码。
2. 点击 **Verify / Confirm（验证 / 确认）** 提交。

### 6.3 支付结果

- **成功**：页面显示支付成功（Subscription active / Payment complete），并提示会员已生效。
- **失败 / 被拒**：常见原因及处理：

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 提示「Card declined」 | 卡余额不足、发卡行拒绝、卡片未开通境外/线上支付 | 换银行卡，或致电发卡行开通「国际/线上支付」 |
| 提示「Security code was declined」 | 安全码输错 | 翻卡片背面核对后重新输入 |
| 提示「Zip / Postal code 错误」 | 邮编与发卡行预留不一致 | 用发卡银行 App 或信用卡账单确认邮编 |
| 一直未收到验证码 | 手机号预留在银行 App 里过期、或被短信拦截 | 检查拦截名单，或联系发卡行更新预留手机号 |
| 提示「已完成支付但 App 内未更新」 | 状态刷新延迟 | 稍等片刻，或重启 App 查看订阅状态 |

---

## 7. 常见问题汇总

| 问题 | 解决办法 |
| --- | --- |
| 在哪看是否订阅成功 | 回到 App 订阅页面查看会员状态；已生效则显示到期时间 |
| 每次订阅都要重新填吗 | 支付成功后银行渠道（如 Stripe 关联卡片）可能记住卡片，下次只需确认，无需重复填写 |
| 卡号被泄露了怎么办 | 尽快联系发卡行挂失补卡；任何情况下都不应把卡号/安全码发给别人 |
| 不支持 xx 国家的卡 | 只能使用发卡行支持国际在线支付（3-D Secure 等）的银行卡 |
| 银联卡可以用吗 | 可以，选择「银行卡」支付并输入银联卡号即可 |
