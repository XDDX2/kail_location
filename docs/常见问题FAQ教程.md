# 常见问题 FAQ 教程

> App 内置「常见问题」页：内容全部来自**后端动态下发**（问题 + Markdown 格式答案），并做了本地缓存——有缓存秒开、无缓存显示加载中，网络失败仍可读缓存。无需登录即可浏览。

## 1. 入口

侧边栏 ☰ → **更多** 分组 → **常见问题**。

## 2. 操作

1. 打开页面：标题「常见问题」，问题卡片列表；
2. **点击任意问题**：展开/收起答案（箭头旋转，单开互斥——一次只展开一个）；
3. 答案支持 **Markdown 渲染**：
   - 代码块、列表、引用正常显示；
   - 长按答案文本可**选中复制**；
4. 页面底部显示最后更新时间「更新于 yyyy-MM-dd HH:mm:ss」；
5. 网络失败：页面显示错误文案 + **重试** 按钮（有缓存时用缓存数据）；
6. 空列表：显示"暂无常见问题"。

## 3. 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 打不开 FAQ / 一直转圈 | 检查网络；等待自动加载缓存 |
| 答案显示不全 | 等网络恢复，点「重试」下拉刷新 |
| FAQ 里没有你的问题 | 联系作者反馈（侧边栏「联系作者」，mailto 邮箱） |

## 4. 帮助按钮（?）

右上角 ?：返回 / 重试 / 点击展开收起 三项角标引导。
