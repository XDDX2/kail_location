# 独立模拟教程

> Kail Location 的「独立模拟」：一个**作用域开关**——先挑一批目标应用，开启之后，在位置 / 路线 / WiFi / 基站 / 步频页面点"开始模拟"，模拟数据就**只对白名单里的应用生效**，其它应用全部读到真实数据。用于"只想给某个 App 假定位，别污染其它应用"的场景。

> **仅 Root 模式**可用（依托 FakeLocation 注入层），侧边栏在 Root 模式下显示。

## 1. 开始之前

- 运行模式 = **Root 模式**，root 已授权。
- **开始独立模拟**时需已登录、订阅或免费次数充足（开启时扣一次免费次数）。

## 2. 操作步骤

### 第一步：添加目标应用

1. 点右上角 **+（选择目标应用）**，弹出「选择目标应用」对话框；
2. 顶部搜索框按名称/包名过滤；列表为已安装应用（系统应用仅保留部分常见前缀，如 腾讯/阿里/百度/高德/美团/华为/小米 等及 Chrome、Google Maps）；
3. 勾选想要"只见假数据"的应用，点 **「确定」**（计数显示"已选择 N 个应用"）。

### 第二步：开启独立模拟

1. 主卡片显示「独立模拟已停止」；下方描述说明生效机制。
2. 列表区显示「已选择的应用（N）」，每条：应用名 + 包名 + 红色删除图标（删除即时生效）。
3. 点 **「开始独立模拟」**（未选任何应用时按钮禁用，并提示"请先选择目标应用"）：
   - 成功 → 状态变 **「独立模拟运行中」**；
   - 已登录校验/免费次数扣除在此步完成。
4. 运行中随时加/删应用都立即生效；点红色 **「停止独立模拟」** 即不再限作用域（恢复对所有应用生效/或随各模拟开关）。

### 第三步：去其它页面开始模拟

- 回到位置模拟 / 路线 / WiFi / 基站 / 步频等页面，正常开始模拟即可——只有你在本页选中的应用能看到假数据。
- 本页不直接产生模拟数据，开关状态与名单实时同步给运行中的服务。

## 3. 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 侧边栏没有「独立模拟」 | 需要 Root 模式 |
| 开启提示未登录/次数用完 | 先登录；检查订阅/次数 |
| 目标应用还是真实数据 | 确认模拟页面（位置/路线等）也处于"开始模拟"状态；重启该应用 |
| 找不到某些系统应用 | 系统应用仅展示固定前缀白名单，去掉系统签名保护的应用无法选择 |

## 4. 帮助按钮（?）

右上角 ?：菜单 / 添加要模拟的应用 / 开始停止模拟 / 移除该应用 四项角标引导。
