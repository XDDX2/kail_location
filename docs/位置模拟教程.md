# 位置模拟操作教程

> Kail Location 的「位置模拟」：把一个位置设为模拟目标后启动模拟，设备将被"搬"到该位置（虚拟定位）。App 启动后默认就在本页面。

## 1. 开始之前

- 已 **登录**（未登录启动模拟时会提示"请先登录后再使用模拟功能"）。
- 已授予 **定位权限**（FINE + COARSE，App 启动时会自动请求）。
- 根据当前运行模式满足对应前置条件（详见《运行模式教程》）：
  - **Developer（开发者）模式**：需在系统「开发者选项 → 选择模拟位置信息应用」中选中本应用；
  - **Root / Xposed / Sandbox**：按对应教程部署好环境。

## 2. 选择模拟位置

### 方式一：地图选点（推荐）

1. 点击目标卡片右上角 **带加号的圆形按钮（+）**，进入选点页（百度地图）。
2. 点击地图选择想模拟的地点。
3. 常用工具栏（右侧竖排按钮）：
   - **图层**：切换普通 / 卫星地图。
   - **输入**：直接输入坐标（支持 纬,经度 或分栏填写；默认 WGS84，勾选「BD09坐标」则按百毒坐标解释）。
   - **定位**：回到当前真实位置。
   - **放大 / 缩小**：调整地图比例。
4. 右上角 **搜索**：输入地点名搜索 POI，点结果直接跳转设置。
5. 点右下角 **确认（✓）**，选点页带回所选位置：名称 + 地址 + 经纬度显示在目标卡片上。

### 方式二：从历史 / 收藏中选择

主界面下方有「常用 / 历史」两个 Tab（对应收藏 / 历史记录）：

- 点击任意一条记录，即把它设为当前模拟位置。
- 每条记录右侧有 **星标（收藏）**、**铅笔（重命名）**、**垃圾桶（删除）** 三个按钮。
- 「常用」Tab 里收藏的位置可 **长按拖动排序**（排前面的更常用）。
- 右上角 **搜索按钮**：按名称或保存时间过滤列表。

> 新选的每个位置会自动保存到本地历史记录（同坐标自动去重、保留收藏状态）。

## 3. 启动模拟

1. 确认目标卡片上显示的 **名称 / 地址 / 经纬度** 是正确的目标。
2. 点击卡片上的 **「启动模拟」** 按钮（绿色），按钮会显示"启动中…"。
3. 启动成功后按钮变为红色 **「停止模拟」**。
4. 此时打开任意地图 / 定位类 App，即可看到设备位置已变为所选位置。

## 4. 模拟中的控制

启动后仍可在卡片上操作（需先点卡片标题区将卡片展开）：

- **摇杆开关**：开启后屏幕上出现**摇杆悬浮窗**（详见下一节）。
- **速/频设置（齿轮）**：弹出设置对话框——
  - **步频模拟**开关：模拟计步器/步数检测数据（仅 Root / Xposed / Sandbox 模式可用，Developer 模式打开会提示需要 Root）；
  - 开启后可调 **步频（60~240 步/分）**，换算速度显示在旁边（如 120 步/分 ≈ 5.0 km/h）。
- **停止模拟**：点击红色按钮立即结束，位置恢复正常。

## 5. 摇杆悬浮窗（走位帮手）

开启摇杆开关后，屏幕上出现半透明摇杆浮窗：

- **白色小球**：点击可展开/收起悬浮面板；也可以直接**拖动小球**控制移动（拖动到哪个方向，位置就往哪边走）。
- 圆点外侧的 **速度调节盘**（"摇杆速度: x km/h"）：拖动滑块可实时改变速度。
- 悬浮面板上还有：
  - **速度设置按钮**：弹出速度模式选择（步走 / 跑步 / 自行车 / 开车）。
  - **历史按钮**：打开「历史记录 / 收藏」小窗口，搜索或点击选点（不用回主界面).
  - **地图按钮**：打开小地图窗口（小地图有"回到当前位置"按钮）。
  - **最小化按钮**：把面板收红成小圆点。

> 摇杆的移动速度档位在「设置 → 移动」中调整（步行 1.2、跑步 3.6、驾驶 10.0 米/秒等）；摇杆视觉样式也可在设置里选「圆形 / 按键」。

## 6. 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 点「启动模拟」无反应 | 先检查是否已登录、免费次数是否够（或订阅是否生效） |
| Developer 模式提示"请在开发者选项中选择本应用" | 进入系统开发者选项 → 模拟位置应用 → 选 KailLocation |
| 模拟后位置没变 | 确认目标位置正确、已经点击"启动模拟"；仍不行可重新选一个位置再启动 |
| 摇杆浮窗不显示 | 确认摇杆开关已开启；部分系统需在「应用设置 → 悬浮窗」中授权本应用 |
| 步频模拟开关灰色 | 步频模拟不支持 Developer 模式，请切换 Root / Xposed / Sandbox |

## 7. 帮助按钮（?）

页面右上角 **?**：点击后全屏遮罩，每个按钮带数字角标，底部出现「按钮说明」图例面板，逐条讲解每个按钮用途；点任意位置关闭。
