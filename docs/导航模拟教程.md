# 导航模拟教程

> Kail Location 的「模拟导航」：沿着一条真实驾车线路（百度地图规划），让模拟位置按设定速度沿途行驶，适合需要"位置沿路线不断变化"的场景。

> 本页面与「路线模拟」的区别：路线模拟是自己画折线随便走；导航模拟走的是百度规划的**真实道路**，更像真的在开车。

## 1. 开始之前

- 已 **登录** 且 **订阅或免费次数充足**。
- 已授予 **定位权限**；百度地图 Key 已配置（否则地图显示/规划不可用）。
- 开发者模式需在系统「开发者选项 → 选择模拟位置信息应用」中选中本应用。

## 2. 操作步骤

### 第一步：进入页面

打开侧边菜单（☰），选择 **「模拟」→ 模拟导航**。

### 第二步：设置起点和终点

- **方法一（在卡片上直接填）**：卡片上两行「起点 / 终点」，未设置时显示"请选择起点 / 请选择终点"。行首两个小图标：
  - **锁图标**：锁定此点，下次规划时保留；
  - **人头图标**：固定为当前定位，每次自动更新。
- **方法二（一键规划，推荐）**：点右下角 **+（一键规划路线）** 进入规划页：
  1. 地图中央有准星，点右下角 **落点按钮**：第 1 次落**起点**、第 2 次落**终点**；
  2. 也可以点右上 **搜索** 按钮，搜索地点设为起点/终点（点击搜索结果切换起点/终点）；
  3. 右侧按钮还可 **定位到当前**、**放大**、**缩小**；
  4. 想添加"途经点等待时间"：规划好后再次点落点按钮，等待点会吸附到路线蓝线上，点 **等待** 按钮弹出"途经点等待时间"输入秒数（0 表示不停留）；
  5. 撤销/纠错：点右下 **撤销**（先撤销等待点 → 终点 → 起点）；
  6. 起终点齐之后点 **确认（✓）** 回到主界面。
- 想全部重来：点卡片右上红色 **删除图标**，清空起终点（已锁定/固定的点不会被删）。

### 第三步：规划路线

1. 主按钮 **「开始规划」**（绿色）。若设置里勾选了 **「多路线」**，百度返回多条候选路线时会弹出多路线窗口：灰色=候选、绿色=当前选中，可点 **「切换路线」/「选择路线」**。
2. 规划完成：卡片出现绿色 **✓ 已规划** 标识，等待点已按路线保存。

### 第四步：开始模拟

1. 点主按钮 **「开始模拟」**（起终点已定且已规划才可点）。
2. 模拟中按钮变为 **「暂停 / 继续」** 与红色 **「结束模拟」**。
3. 运行中想改速度：点 **齿轮** 打开「设置速度 (km/h)」对话框（默认 60）。

### 第五步：历史路线管理

- 页面底部两个 Tab：**「收藏」/「历史位置」**，右上搜索可过滤。
- 每条记录显示 `起点 → 终点`：
  - **星标**：收藏；
  - **铅笔**：重命名；
  - **垃圾桶**：删除（首次弹确认，可勾选"10分钟内不再提醒"）；
- **收藏页支持长按拖动排序**。
- 历史最多保留最近 10 条。

## 3. 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 「开始规划」按钮灰色 | 起点或终点未设置，先补全 |
| 「开始模拟」按钮灰色 | 先点「开始规划」并成功（出现"已规划"） |
| 搜索地点无结果 | 检查网络、百度地图 Key 配置 |
| 定位失败提示 | 下滑点时因无精确位置失败，改用搜索或直接拖地图落点 |
| 多路线弹窗没出现 | 百度只返回一条路线时就不会弹，属正常 |

## 4. 帮助按钮（?）

页面与规划页的右上角 **?**：数字角标 + 底部图例，逐条讲解每个按钮用途（退出：点任意位置）。
