# Root 应用隐藏教程

> Kail Location 的「Root与应用隐藏」：对选定应用**隐藏本机检测痕迹**——隐藏 Root（Magisk/Xposed/框架痕迹）与隐藏已安装应用列表，让目标应用（如银行、政务、风控严的 App）探测不到你的 Root 环境和真实装机环境。

> **仅 Root 模式**可用（FakeLocation 注入层 + 进程内防检测 Hook，**不使用 pm hide**），侧边栏在 Root 模式下显示。

## 1. 开始之前

- 运行模式 = **Root 模式**，root 已授权。
- 本功能**无需登录/付费/免费次数**，直接可开。
- 机器最好有可用的注入链（首次开启会自动部署并注入目标应用进程，需等待几秒）。

## 2. 操作步骤

### 第一步：选择目标应用

1. 点右上角 **+** → 弹「选择目标应用」对话框（搜索 + 多选，同独立模拟）；
2. 勾选完成后点 **「确定」**；列表显示「已添加的应用（N）」，右侧红色图标可逐个移除（实时生效）。

### 第二步：选择要隐藏的内容

主卡片「隐藏设置」两种开关：

- **隐藏 Root**：默认开启。对目标应用隐藏 Root / 框架（Magisk、LSPosed 等）痕迹；
- **隐藏应用列表**：默认关闭，且**只有「隐藏 Root」开启时才可启用**。开启后目标应用看到的已安装应用列表会被过滤（并同步防检测规则）。

> 若两个开关都没开、也没选应用，开始按钮禁用并提示"请先选择目标应用并至少开启一项隐藏"。

### 第三步：开始隐藏

1. 点 **「开始隐藏」** → 状态变 **「隐藏运行中」**，后台自动部署注入目标应用进程；
2. 模拟中**修改开关、增删应用都立即生效**；
3. 点红色 **「停止隐藏」** → 状态回「隐藏已停止」，系统清理配置并对目标应用做强制停止（清掉进程内残留），避免应用"看到一半"的脏状态。

## 3. 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 侧边栏没有该入口 | 需要 Root 模式 |
| 「隐藏应用列表」开关灰色 | 先打开「隐藏 Root」开关 |
| 目标应用仍检测到 Root | 重启该应用（Hook 需要进程重新加载）；确认真机 root 权限授权给本应用 |
| 开启后其它应用异常 | 隐藏仅对目标应用生效，其它应用不受影响；仍异常请停止隐藏并反馈 |

## 4. 说明

- 底层通过 FakeLocation 注入层（`oem_integrity` 防检测规则 + 进程内 RootHideHook）实现；拦截与 `pm hide` 无关。
