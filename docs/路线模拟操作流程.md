# 路线模拟操作流程

> Kail Location 的「路线模拟」功能：在地图上规划一条路线，让虚拟位置沿路线匀速移动，用于验证依赖位置变化的应用或业务流程。

## 1. 开始之前

- 先确认已 **登录** 且 **模拟次数充足**（未登录或被拦截时会提示）。
- 确保已授予 **定位权限**。
- 不同运行模式需要满足各自条件：

| 模式 | 额外条件 |
| --- | --- |
| Developer | 在系统「开发者选项 → 选择模拟位置信息应用」中选中本应用 |
| Root | 已授予 Root 权限；开机满一段时间后再启动（刚开机启动可能会卡死或重启，请耐心等待提示时间） |
| Xposed / Sandbox | 已按对应方式部署好模块/沙盒环境 |

## 2. 操作步骤

### 第一步：进入路线模拟页面

1. 打开 Kail Location，点击左上角 **☰ 菜单**。
2. 在抽屉菜单中选择 **「路线模拟」**。

### 第二步：规划一条路线

1. 点击顶部目标卡片右上角带 **加号** 的圆形按钮，进入地图规划页。
2. 点击右侧中间 **标点按钮**（定位图标）进入标点模式。
3. **拖动地图**，让屏幕中央的定位图标对准目标地点，松手即记下第一个途经点；继续拖动即可依次添加后续途经点，蓝色折线会随之画出来。
4. 重复以上操作，把整条路线所需的地点都标完。

> 其他加点的辅助方式：
> - **搜索**：点顶部搜索图标，输入地点名并选中结果，地图自动跳转，可继续标点。
> - **历史位置**：点右上一「历史」按钮，从历史位置记录中选点。
> - **坐标输入**：点右下「输入」按钮，直接输入纬度、经度（支持 WGS84，或勾选「BD09坐标」）后地图跳转。
> - **等待时间**：点右下 **「等待」** 按钮，可给最新标好的点设置停留秒数——模拟到达该点后会停留这么久再继续走（0 表示不停留）。
> - **撤销**：每点一次右下「撤销」按钮，可移除最后一个途经点。
> - 如有需要，可用右侧按钮「定位到当前位置 / 放大 / 缩小 / 切换卫星图」。

5. 标好 **至少 2 个点** 后，点击右下角 **对勾** 确认。路线即被保存，并自动出现在列表中。

### 第三步：把路线设为目标

- 回到列表页后，点击想要模拟的那条路线卡片，即可将其设为上方「目标路线」。
- 对某条路线还可以：
  - 点 **星标**：收藏（收藏后可长按拖动排序）；
  - 点 **定位图标**：再次编辑这条路线；
  - 点 **铅笔**：重命名；
  - 点 **垃圾桶**：删除（首次删除会弹出确认，可勾选不再提醒）。

### 第四步：设置模拟参数

点击目标卡片上的 **「速/频」**（或旁边小图标），在弹窗中调整：

- **运动速度**：拖动滑块设置（0~120 km/h）。
- **交通方式**：步行 / 跑步 / 骑行 / 驾车 / 飞机。
- **速度浮动**：开启后速度会有小幅随机波动，更接近真实运动。
- **步频模拟**（仅 Root / Xposed / Sandbox）：开启后可再调步频（60~180 步/分）。

另外，目标卡片上还有 **「循环」开关**：开启后走到终点会从头再走一遍。

### 第五步：启动模拟

点击目标卡片上的 **「启动模拟」** 按钮。按钮会短暂显示「启动中…」，随后变为「暂停 / 结束模拟」即表示已开始。

启动成功后，打开任意地图类 App，即可看到虚拟位置沿规划路线移动。

### 第六步：运行中的控制

模拟期间，仍可在目标卡片上操作：

- **暂停 / 继续**：暂停时位置停住不动，点击「继续」恢复移动。
- **结束模拟**：立即停止，位置恢复正常。
- **实时调速 / 改步频**：再次打开「速/频」弹窗调整，立即生效。
- **循环开关**：随时切换，立即生效。
- **延长路线**：模拟还在走的时候，点右上 **加号** 再次进入规划页，地图会直接定位到当前终点，继续往后标点再点对勾确认，新增路段会追加到正在走的路线里，模拟会自动接着走下去。

## 3. 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 点「启动模拟」没反应或提示启动失败 | 先检查是否已登录、次数是否用完、对应模式的权限是否满足 |
| 提示「请先添加并保存路线」 | 路线点数不足，至少标 2 个途经点并点对勾保存 |
| Root 模式提示系统未就绪 | 刚开机系统还没稳定，等提示的时间到了再试 |
| 步频模拟开不了 | 该模式需要 Root / Xposed / Sandbox，Developer 模式下不可用 |
| 搜索无结果 | 未配置百度地图 API Key，请先在应用内按提示配置 |
| 模拟后位置没有变化 | 确认目标路线已选中、已启动成功；仍不行可导出日志反馈给开发者 |

## 4. 保存了什么

- 你规划的每条路线、以及它的收藏/名称/排序，都保存在本机应用数据里，卸载或清除数据后即清空。
- 想从头开始？清除应用数据即可重置所有路线与设置。
