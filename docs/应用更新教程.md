# 应用更新教程

> Kail Location 支持**自动检查更新**（App 每次启动静默检查）+ **手动检查** + **强制更新**。更新通道：后端（yudao app-version/check）→ GitHub Releases → HEAD 探测兜底；下载来源后端 fileUrl → GitHub 备用，下载后须校验字节数，失败自动切换源。

## 1. 自动检查

- App 启动（主界面）时静默调用后端检查：
  - 有更新 → 弹 **更新弹窗**；
  - 无更新 → 不打扰（无任何提示）。

## 2. 更新弹窗

| 元素 | 说明 |
| --- | --- |
| 标题 | 「新版本可用 vX.Y.Z」 |
| 正文 | 更新说明（后端 description）+ 安装包大小（如 12.34 MB） |
| 按钮 | **「立即下载」**（下载中变"升级文件下载中。。"且禁用）、**「取消」** |

- **强制更新**（forceUpdate=true）：弹窗无「取消」按钮、点遮罩也关不掉——必须下载安装；
- 下载进度条显示「下载中… n%」（无大小信息时不定进度转圈）；
- 下载完成自动调起**系统安装器**安装。

## 3. 手动检查

- 抽屉菜单旧入口「检测更新」（新抽屉未渲染该菜单项）；
- 相应代码路径在部分页面 onNavigate 中仍保留，用法：调用后提示：
  - 无更新 → 「当前已是最新版本」；
  - 检查失败 → 「检查更新失败: <原因>」。

## 4. 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 提示检查失败 | 大陆网络可能无法直连 GitHub；后端检查失败才回退 GitHub，请稍后再试 |
| 下载卡住/失败 | 自动切换备用源；仍失败查看网络（FileProvider 安装要求外部存储可写） |
| 更新后模拟失效 | 重装 Xposed 模块（版本需与 App 一致）或重新授权 root；版本大更新请重新配置 |
| 强制更新关不掉 | 属于服务端策略，正常行为：装新版本即可 |
